# 藤丰园林 · 植物养护智能助手 — 开发文档

---

## 一、项目概览

藤丰园林植物养护智能助手，核心功能：**拍照识别植物 → AI 分析养护建议 → 建立植物档案 → 定时提醒养护**，附带植物商城。

- **平台**：微信小程序
- **后端**：微信云开发（云数据库 + 云存储 + 云函数）
- **AI 服务**：阿里云百炼 qwen-vl-max / qwen-turbo
- **语音服务**：百度语音识别
- **云环境 ID**：`cloud1-8gsievbe0e390ea8`

## 三、商城与订单开发流程

### 订单状态机

```
pending（已提交）──支付──→ paid（已支付）──发货──→ shipped（已发货）──完成──→ completed（已完成）
    │                      │                                   
    └──取消──→ cancelled（已取消，库存恢复）
```

### 完整购买链路

```
商城首页(mall.js) → 商品详情(product-detail.js) → 购物车(cart.js) → 结算(checkout.js) → 订单(order.js)
读cloud products   调getProductDetail云函数       读本地cart       读tempCheckoutCart    读cloud orders
                   写本地cart/favorites/         验cloud products   读mall_addresses      取消→cancelOrder
                   browseHistory                结算→写temp-      提交→createOrder云函数      云函数(事务)
                                                CheckoutCart
                                                                    ↓ redirectTo
                                                              订单详情(order-detail)
                                                                    ↓
                                                              支付(payment.js)
                                                              确认→payOrder云函数
```

### 每一步的数据流

| 步骤 | 页面 | 读 | 写 | 说明 |
|------|------|-----|-----|------|
| 1. 浏览 | `mall.js` | 云 `products`(500条) | — | 按 category 分组，搜索在内存过滤 |
| 2. 详情 | `product-detail.js` | 云函数 `getProductDetail` | 本地 `cart`/`favorites`/`browseHistory` | 立即购买写 `tempCheckoutCart` |
| 3. 购物车 | `cart.js` | 本地 `cart` + 云 `products`(验库存) | 本地 `cart`/`tempCheckoutCart` | 勾选后结算 |
| 4. 结算 | `checkout.js` | 本地 `tempCheckoutCart` + 云 `mall_addresses` | 云函数 `createOrder` → 云 `orders` | 提交后清临时数据 |
| 5. 订单 | `order.js` | 云 `orders`(where openid) | 云函数 `cancelOrder` → 改 `cancelled` + 恢复库存 | 事务保证 |
| 6. 支付 | `payment.js` | 云 `orders` | 云函数 `payOrder` → 改 `paid` | 验证归属 |

### 涉及的云函数（商城+订单）

| 云函数 | 调用方 | 入参 | 事务 | 说明 |
|--------|-------|------|------|------|
| `getProductDetail` | 商品详情 | `{id}` | ❌ | 按 number id 查 products |
| `createOrder` | 结算页 | `{buyItems, address}` | ❌ | 查价格→生成订单 pending |
| `payOrder` | 支付页 | `{orderId}` | ❌ | 验归属+状态→改 paid |
| `cancelOrder` | 订单列表 | `{orderId}` | ✅ | 改 cancelled + 恢复库存 |
| `shipOrder` | 管理后台 | `{orderId}` | ✅ | pending→shipped（前端未调） |
| `completeOrder` | 管理后台 | `{orderId}` | ✅ | shipped→completed（前端未调） |

### 存储分工（商城+订单）

| 数据 | 存储 | 原因 |
|------|------|------|
| `products` | 云数据库 | 管理员维护 |
| `orders` | 云数据库 | 涉及钱，必须上云 |
| `mall_addresses` | 云数据库 | 地址长期资产 |
| `cart` | 本地 storage | 临时购物行为 |
| `favorites` | 本地 storage | 收藏（暂未上云） |
| `browseHistory` | 本地 storage | 浏览历史 |

## 四、云函数清单

| 云函数 | 用途 |
|--------|------|
| `login` | 获取用户 openid（app.js 启动时调用） |
| `createOrder` | 下单：查商品价格 → 生成订单（状态 `pending`） |
| `payOrder` | 支付：验证归属 → 改状态 `paid` |
| `cancelOrder` | 取消订单 + 恢复库存（带事务） |
| `shipOrder` | 发货：`pending` → `shipped`（管理端预留，前端未调） |
| `completeOrder` | 完成：`shipped` → `completed`（管理端预留，前端未调） |
| `getNextId` | 自增 ID 生成器（带防冲突重试，前端未直接调） |
| `getProductDetail` | 按业务 ID 查商品详情 |
| `plantReminder` | 定时查过期提醒 → 发订阅消息 → 更新下次时间 |
| `plantReminderTrigger` | 定时触发器，内部调 `plantReminder` |

## 五、云数据库与云存储

### 数据库集合

| 集合 | 用途 | 主要字段 |
|------|------|---------|
| `users` | 用户注册记录 | `_openid`, `createTime` |
| `products` | 商品目录 | `id`(number), `name`, `price`, `stock`, `image`, `category`, `tags`, `specs` |
| `orders` | 订单 | `openid`, `items[]`, `address`, `totalPrice`, `status`(pending→paid→shipped→completed/cancelled) |
| `user_plants` | 植物档案 | `_openid`, `nickname`, `species`, `imageUrl`(cloud://), `location`, `latitude`, `longitude`, `plantDate` |
| `plant_reminders` | 养护提醒 | `plantId`, `type`, `frequency`, `nextReminderTime`, `isActive`, `_openid` |
| `mall_addresses` | 商城收货地址 | `name`, `phone`, `province`, `city`, `district`, `detail`, `isDefault`, `fullAddress` |
| `plant_addresses` | 植物位置地址 | `address`, `latitude`, `longitude` |
| `recognition_history` | 植物识别历史 | `imageUrl`(cloud://), `basicInfo`, `growthStatus`, `careTips` |

> 除了商品之外的所有集合安全规则均为：`{ "read": "doc._openid == auth.openid", "write": "doc._openid == auth.openid" }`

### 云存储路径

| 路径 | 内容 | 上传页面 |
|------|------|---------|
| `user-avatars/{timestamp}-{random}.png` | 用户头像 | login, profile |
| `plants/{timestamp}.jpg` | 植物图片 | addPlant |
| `recognition/{timestamp}.jpg` | 识别图片 | plantRecognition |
